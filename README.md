# ec-mos-toolkits

This is a toolkit for interfacial electrochemistry of metal oxide semicondutors.

---

## Installation

You can install the package directly from the GitHub repository:

```bash
pip install git+https://github.com/Cyclones-X/ec-mos-toolkits.git
```

Or from source:

```bash
git clone https://github.com/Cyclones-X/ec-mos-toolkits.git
cd ec-mos-toolkits
pip install .
```

---

## Upgrade

Currently this toolkits is developing, and the version would not be always changed. Therefore, it is recommended to upgrade it with `--force-reinstall`.  

Similarly, you can upgrade from GitHub repository:

```bash
pip install --upgrade --force-reinstall git+https://github.com/Cyclones-X/ec-mos-toolkits.git 
```

Or from source:

```bash
git clone https://github.com/Cyclones-X/ec-mos-toolkits.git
cd ec-mos-toolkits
pip install --upgrade --force-reinstall .
```
